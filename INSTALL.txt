ADVANCED K9 v1.7.2-beta — DRAG-AND-DROP INSTALL

1. Close GTA V and RAGE Plugin Hook.
2. Open the compiled release ZIP.
3. Drag everything from the release ZIP into the folder containing GTA5.exe.
4. Allow Windows to merge the Plugins folders. This does not replace LSPDFR.
5. Start RAGE Plugin Hook and ensure "Load all plugins on startup" is enabled.
6. Enter Story Mode, start LSPDFR, and go on duty.

Correct file locations
  LemonUI.RagePluginHook.dll
  Plugins\AdvancedK9.dll
  Plugins\LSPDFR\AdvancedK9\AdvancedK9.ini

Remove any older copy at Plugins\LSPDFR\AdvancedK9.dll. AdvancedK9 is a
RAGE Plugin Hook plugin that monitors LSPDFR duty state; it is not loaded by
the LSPDFR sub-plugin loader.

Controls
  Left Ctrl + K   Deploy/dismiss K9
  Left Ctrl + J   Command menu
  Left Ctrl + U   Kennel/profile menu
  Left Ctrl + C   Dog camera
  Left Ctrl + L   Leash
  Hold V          AI push-to-talk

AI voice is optional. Keyboard controls need no key or internet connection.
Voice can be activated or disabled from either AdvancedK9 menu. Put the key
directly in Plugins\LSPDFR\AdvancedK9\AdvancedK9.ini, without quotes:

  [Voice]
  Provider=Groq
  ApiKey=gsk_your_key_here

Save the file, then restart RAGE Plugin Hook so the plugin reloads it. The key
is never displayed or logged. ApiKeyEnvironmentVariable remains an optional
fallback when ApiKey is blank. See README.md for OpenAI settings.

Required before installation
  GTA V Story Mode, ScriptHookV, RAGE Plugin Hook, LSPDFR, Policing Redefined,
  and Common Data Framework.

Optional breed models are not bundled. Follow the links in README.md if wanted.
