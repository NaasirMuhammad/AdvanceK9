# Build 888 — EMS stretcher test
Install the complete package over Build 887 and fully restart. Core and bridge: 0.24.1.7.
The stock wheeled ambulance stretcher is m25_2_prop_m52_gurney_01a (mp2025_02). Existing v_med_emptybed overrides are ignored; a valid custom stretcher can still be selected. BitePatientStretcherPatientZ is the height above wheel-bottom, default 0.85 m. The medic uses an upper-body push approximation while the prop tracks ground height; visual alignment needs in-game testing.
The patient must visibly play the lying clip and be attached before transport handoff. The bridge checks the active player pursuit, attempts per-patient removal if the installed public API supports it, and ends a pursuit only when the patient is its sole member. If unresolved, departure waits and retries; an unrelated pursuit is not cleared. Third-party scripts may still require cooperation.
Test from an active single-suspect pursuit: request hospital transport after a bite, verify wheel contact, lying patient, and pursuit closure at stretcher loading. Confirm police do not chase the departing ambulance. Repeat with two suspects and check that the other remains in pursuit. Test an ordinary no-pursuit transport as well. Include the RPH log if transport waits.
