ADVANCED K9 CUSTOM PORTRAITS

Place square PNG portraits in this folder. Recommended size: 256x256 or 512x512.

Priority:
1. PortraitFile configured for the K9 profile
2. Model file, such as a_c_shepherd.png
3. Breed file, such as german_shepherd.png
4. default.png
5. Built-in safe breed badge

Portraits are cached. Changing the selected model, breed, profile, or PortraitFile refreshes the cache.
